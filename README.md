# Детишки-шахматишки

Детская игра-обучалка шахматам: Лягуха-Малюха объясняет фигуры, шах и мат, рокировку, защиту, вилки и пешечный бой. Всё в одной веб-странице, работает в браузере телефона и компьютера без интернета.

Игра — один файл `index.html`, без сборки. Открывается на компьютере, планшете и телефоне. Прогресс и настройки хранятся в памяти браузера.

## Что внутри

- **Четыре части:** знакомство с фигурами (5 заданий), шах, мат и рокировка (10), защита, вилки и пешечный бой (20), пешечный бой с ленивцами, зебрами и львами (5 уровней).
- Порядок расстановки каждый раз немного новый, поэтому задания решают, а не заучивают.
- Ребёнок нажимает на розовые кружки, фигура ходит туда; нажатие на фигуру повторяет, как она ходит.
- Задания читает Лягуха-Малюха: записанный голос, а без него — синтез речи устройства.
- Звук можно выключить кнопкой в шапке.

## Запуск

Можно открыть `index.html` как файл. Для офлайн-открытия и добавления на экран «Домой» нужен HTTP(S)-сервер:

```bash
C:\TST\python.exe -m http.server 8777 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8777/index.html`.

## Проверка

- Титульный экран, четыре части, голос Лягухи-Малюхи, поле с фигурами; ошибок в консоли нет.
- Мобильная вёрстка 412 px без горизонтальной прокрутки.
